# 말을 숫자로 바꾸는 20가지 방법 — NLP 치트시트를 5층 지도로 다시 읽기

자연어 분석과 LLM · 연구실 해설 01

컴퓨터는 숫자밖에 모르는데, 어떻게 우리가 쓴 글을 읽을까요?
NLP 기술 20가지를 「글자를 숫자로 → 숫자로 고르기 → 뜻을 좌표로 → 순서와 문맥 → 미리 배운 언어 모델」 다섯 층과 과업 5개로 다시 정리한 비전공자용 해설 페이지입니다.

- 페이지 보기: https://adminmrobo.github.io/nlp20_five_floor_map/
- 층마다 손계산 한 번(로그 · 조건부확률 · 피타고라스 · 지수함수)과 직접 만지는 실험
- AI 판단 코너: 치트시트 문장 8개 점검
- 대결: 낱말 하나씩 vs 두 낱말 묶음 (나이브 베이즈 감성 분류)
- 지식 색인과 온톨로지·서지 꾸러미(BibTeX · RIS · Turtle · CSV · kg.json)
